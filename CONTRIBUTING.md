# Contributing to VERITY

VERITY is intentionally early-stage. The most useful contributions are small, reproducible improvements.

## Good first contributions

- add tests for edge cases
- improve provenance handling
- document failure modes
- propose evaluation datasets
- improve CLI ergonomics
- report contradictions or false-positive extraction cases

## Pull requests

1. Explain the problem.
2. Keep changes focused.
3. Add or update tests.
4. Do not add hidden network calls or telemetry.
5. Preserve the distinction between evidence and inference.

Please do not submit fabricated benchmarks, adoption numbers, or research results.
