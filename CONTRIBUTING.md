# Contributing

Thanks for helping improve Opportunity Intelligence Agent.

## Development

1. Fork the repository.
2. Create a focused branch.
3. Add or update tests for behavioral changes.
4. Run the test suite locally.
5. Open a pull request describing the problem, approach, and verification.

## Contribution principles

- Preserve source provenance.
- Never present an inference as a verified fact.
- Keep human approval explicit for external actions.
- Prefer small, reviewable changes.
- Do not add credential harvesting, unauthorized access, or evasion functionality.

## Issues

Use issues for reproducible bugs, feature proposals, and research questions. Include a minimal reproduction when possible.
