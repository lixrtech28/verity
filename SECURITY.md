# Security Policy

VERITY is intended for authorized research workflows. Do not use it to bypass access controls, evade anti-abuse systems, fabricate participants, or present synthetic evidence as human evidence.

## Reporting a vulnerability

Please avoid public disclosure of an unpatched security issue. Open a private security report through GitHub's security reporting mechanism when available.

Include:

- affected version or commit
- reproducible steps
- impact
- suggested mitigation, if known

Research-integrity issues such as provenance loss, evidence substitution, or unsafe external actions are also welcome.
